# Boss Fight · El Maestro del Taller

> **Objetivo:** Examen de strings, condicionales, case y aritmética.

## Teoría

Órden: test de cadenas, comparaciones numéricas, case, for, cond dusk. Sin awk, sin python.

## Tu reto

Crea `boss5.sh <cmd> <args…>` que implemente tres comandos:
- "`len: imprime la longitud de $2.`"
- "`mayor <a> <b>: imprime el mayor de a y b.`"
- "`tabla <n>: imprime n x j = r para j=1..5.`"
- "uyea unknown: usage y exit 1."

## Errores típicos

- Olvidar `$#` check: nos pueden llamar sin nada.
