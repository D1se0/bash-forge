# Aritmética: (( )) y $[ ]

> **Objetivo:** Sumar, restar, multiplicar y comparar números enteros.

## Teoría

`(( 5+3 ))` imprime el resultado; `(( $a > $b ))` es un test numérico. `$(( ))` se usa dentro de texto: "total: $(( $x + 1 ))".

## Tu reto

Crea `mate.sh` que con $1 y $2 imprima tres líneas: suma, producto y el mayor.

## Errores típicos

- Usar [ para comparar (cadenas) en vez de (( )) para números.
- Olvidar $(()) alrededor si imprimes como texto.
