# Boss Fight · El Aprendiz de la Fragua

> **Objetivo:** Examen de nivel 0: script ejecutable + carpetas + README a la vez.

## Teoría

Cada nivel culmina con un **Boss Fight**: examen práctico todo-junto sin teoría nueva. Se puntúa: ficheros existentes, shebang/bit +x, salida correcta y limpieza (sin mensajes de error sueltos).

## Tu reto

Completa todo: 
1. `forge.sh`: shebang + imprime `Fragua encendida`, ejecutable.
2. Carpeta `forge/log` (una orden).
3. `README.md` con una línea que empiece por `# Forja de`.
4. Ejecuta `./forge.sh`.

## Errores típicos

- Ejecutar `bash forge.sh` y pensar que vale: el check pide `./forge.sh` (pide +x).
- `mkdir forge/log` sin `-p`: falla si `forge/` no existe (aquí no existe).

> ⚡ Con esto cierras nivel 0: **Aprendiz de la fragua** desbloquean siguientes niveles. ¡A por el nivel 1 (variables)!
