# Recursividad con funciones

> **Objetivo:** Llamadas a la misma función siempres paradas por un caso base.

## Teoría

La recursión en bash SÍ existe. Clave: caso base claro. Si te olvidas, el stack explota.

## Tu reto

Crea `factorial.sh <n>` que imprima el factorial de n con recursión.

## Errores típicos

- No parar el caso base: se cae con too many open files (se come el stack).
