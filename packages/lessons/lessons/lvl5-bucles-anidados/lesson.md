# Bucles anidados y tablitas

> **Objetivo:** Construir tablas multiplicativas con dos for juntos.

## Teoría

Un for dentro de otro. Recuerda que el `; done` cierra el interno antes de que el externo continúe.

## Tu reto

Crea `tabla.sh <n>` que imprima `n x j = resultado` para j=1..10.

## Errores típicos

- Olvidar Tab semánticamente dentro del for: no importa sintaxis, pero el ; sí.
